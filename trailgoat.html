TrailGoat / Founder-built venture

Built for
the long run.

A connected running product, from a useful plan to a memorable identity.

Product design / Web application / 3D brand motion

Visit TrailGoat ↗ (opens in a new tab)

The idea

A trail run is a series of decisions.

Route, pace, fueling, and kit belong to the same day out. TrailGoat brings those decisions into a connected product for trail and ultra runners.

01 /

A clear way into the product.

The website introduces the experience through the terrain and the decisions runners need to make. A direct path to planning sits alongside course discovery.

02 /

An interface built around the run.

Course planning, pacing, and fueling tools give the product its structure. The design keeps those related tasks within a recognizable visual system.

03 /

A character beyond the interface.

The brand film takes TrailGoat into three dimensions: blocks assemble into the goat, the character flips, and the pieces resolve into the wordmark.

Interactive storytelling

Show the plan
taking shape.

The product’s scroll-driven story connects the course, elevation, pacing, and fueling in one visual sequence.
