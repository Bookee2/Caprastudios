What's trending that helps Capra

I went through all 34 repositories on GitHub Trending (15 today, 19 this week) and read the code of the five that touch what Capra does: motion, video, marketing, testing and engineering practice. One stands out clearly.

Short versionHyperFrames is the find. It turns HTML pages into frame-exact MP4 videos, supports raw WebGPU, and comes as a Claude Code plugin. It could turn the motion lab and the koi pond into real video for social posts and the marketing room. Everything else on the list is either "maybe, for client work" or overlaps something you already have.

Worth trying

heygen-com/hyperframesTry first

Write HTML, render video · Apache-2.0 · by HeyGen · updated today · 3,011 stars this week

It renders an HTML page into a deterministic MP4: the same input always gives exactly the same frames. Animations must be seekable, meaning the renderer can jump to any moment and draw that exact frame. It has adapters for GSAP (the default), CSS keyframes, Lottie, Three.js, Anime.js and raw WebGPU. It installs as a Claude Code plugin with 21 skills, including motion-graphics, product-launch-video, embedded-captions and music-to-video.

  • Why it fits: our showpieces are already HTML and WebGPU (pond.js, the motion lab, the GPU stages). Today, turning them into video means screen recording or a Blender render. With HyperFrames, the same page becomes a clean 4K clip for social posts, the marketing room's video tab, or client pitches.
  • The catch: WebGPU pieces must draw from the time HyperFrames gives them, not the clock, and must redraw when it seeks. The pond's koi are a step-by-step simulation, so jumping to second 8 means running the simulation forward from the start. That's possible, but it's real work. The CSS and canvas pieces in the motion lab would be easier first targets.
  • Trial: install the plugin in a scratch folder and render one motion-lab piece to a 10-second MP4. Its renderer launches Chrome with WebGPU flags; check that against our GPU code.

coreyhaines31/marketingskillsCherry-pick

Marketing skills for Claude Code · MIT · updated 2 Oct · 270 stars today

About 50 marketing skills, including CRO, copywriting, ai-seo, programmatic-seo, schema, site-architecture, directory-submissions, free-tools, lead-magnets, marketing-psychology, launch and video.

  • Why it fits: Capra has an SEO standard, a marketing room and a growth note in the vault.
  • The catch: it overlaps heavily with what you already have, namely the claude-seo suite (schema, GEO/AI search, sitemaps) and the marketing plugin (campaigns, content, SEO audit). Installing all of it would mean three tools competing for every SEO question.
  • Worth taking: the few with no equivalent here. directory-submissions and free-tools suit a local studio building links, and lead-magnets fits the AI consulting page. Since it's MIT, you can copy just those skills.

tester-army/e2eFor client apps

AI-driven end-to-end tests for web and mobile · Apache-2.0 · updated today · 344 stars today

Tests are written partly in plain English (for example, an agent step like "upgrade the workspace to the Pro plan"), run on Playwright or iOS and Android simulators, and are checked by normal assertions. The smart part is that once an agent step passes, its actions are recorded and replayed with no AI calls until the app changes. That keeps tests cheap and repeatable.

  • Why it fits: not the studio site, which is static and already well covered by build checks. It does fit the apps: TrailGoat's planner and Purple Squirrel's hiring flow are multi-step journeys where brittle selector-based tests are painful. It also covers iOS simulators.
  • The catch: the project is young and the record-and-replay idea is unproven at scale. It's worth one pilot test on a single TrailGoat flow before committing.

addyosmani/agent-skillsRead, don't install

Engineering-practice skills · MIT · by Addy Osmani (Chrome team) · updated 3 Oct

About 25 skills covering a spec, plan, build, test, review and ship cycle, plus performance-optimization, browser-testing-with-devtools and a /webperf command. It's solid but generic, and your engineering plugin and existing review loop already cover most of it. The performance-optimization skill and the /webperf command are worth reading for the Core Web Vitals side of the SEO standard, since Addy is a leading voice on web performance.
