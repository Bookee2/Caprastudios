Standard on every site we build

Two pieces make this standard rather than a one-off:

The build gate (scripts/seo.mjs). The site won't build, and nothing publishes, if any page misses any of these:
  • a title and description of the right length, not repeated on another page
  • a canonical link
  • share tags with an image file that actually exists
  • a favicon and touch icon
  • exactly one H1
  • alt text on every image
  • valid structured data
A test proves it rejects a bare page.
The written standard (docs/SEO-STANDARD.md). It covers what's automated, which structured data to include for each kind of page, and the seven launch steps done by hand for each client. It also has the line we tell clients: we make the site fully ready for search, but rankings depend on content, competition and time, so we don't promise positions.

On the site itself, the homepage's Web line, the Web page and the chat assistant now say every site launches ready for search. The homepage structured data also lists SEO as a service.
